## Implemented placement plan

- Homepage: real group-departure image, two real fleet/support images, and real trip-evidence image. All remain below the fold and lazy-loaded.
- Public Trips: alternating editorial section using a departure/boarding image and a group image after the tour catalog.
- Destinations: destination-neutral supporting imagery with explicit text that exact locations are not asserted.
- About: six-image real-trip gallery and a real group/coaster fleet image, while retaining the verified office image and factual story.
- Reviews / Trip Evidence: curated ten-image editorial gallery with factual captions only.
- Tour product pages: unchanged because destination identity cannot be confirmed from the new files.
- Corporate, university, custom and honeymoon pages: unchanged because customer context cannot be confirmed.
- Videos: none published.

## Accessibility and delivery decisions

- Every meaningful photo has factual alt text without names, demographics, testimonial language or unverified locations.
- Captions describe only visible Lexuz trip context.
- The reusable gallery uses semantic `figure` and `figcaption` elements.
- All new media is below the fold, uses Next.js Image, explicit source dimensions or `fill` with a reserved grid row, responsive `sizes`, and default lazy loading.
- No lightbox was added: it would introduce client-side JavaScript for limited conversion value. The lightweight editorial grid is sufficient.
